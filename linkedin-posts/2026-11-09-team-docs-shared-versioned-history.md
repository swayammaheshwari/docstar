## Post

"Who changed this, and what did it say before?" Every team asks that about a runbook at some point, usually in the middle of an incident.

In DocStar, documents are shared with the team and versioned by default. You can list a document's versions, see the version number, who created it and when, and open the content of a specific earlier version.

So the answer is in the doc itself, not in someone's memory or a chat thread.

It also means a doc is not a private file that only one person can find. Specs, onboarding notes and decisions sit in one shared place, and the same content can later be published as product docs, help docs, API docs or a blog.

If your team's docs are hard to trust, give DocStar a look: https://docstar.io
