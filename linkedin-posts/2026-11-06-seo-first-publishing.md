## Post

Publishing a doc is only half the job. People still have to find it.

In DocStar, SEO is part of the publish step, not a plugin you add later.

Every published page gets a title and meta description from its page settings, plus keywords where you set them. Each page also carries a canonical URL, Open Graph and Twitter card tags for clean link previews, and schema.org JSON-LD that describes the page to search engines.

Sites on a custom domain get a generated sitemap.xml and a robots.txt, so crawlers can discover your pages without extra setup.

The same approach applies whether the content is a help article, an API reference or a blog post, because they all come from one source.

Write once, set the page meta, publish. The search plumbing is already there.

Try it: https://docstar.io
