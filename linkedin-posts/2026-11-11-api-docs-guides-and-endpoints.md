## Post

An endpoint list is not documentation. Developers also need the guide that explains why, and when, to call it.

In DocStar, a published API collection becomes a public docs site where the endpoint views and your written guides sit side by side. Readers can browse the reference and try endpoints interactively, then move to the how-to page without leaving the site.

The site is server-rendered, so pages load fast and can be indexed. You can publish it on a custom domain with your own theme, light and dark mode, and custom navigation.

Because guides and reference are written in the same workspace, one team can keep both current instead of maintaining a generated reference in one tool and a wiki in another.

If your API docs are split across tools, see how a published collection looks: https://docstar.io
